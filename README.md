# ペット用フードのカロリー＆月額コストスマート計算機

愛犬・愛猫の年齢や体重、現在のフード情報を入力するだけで、1日の給餌量と1ヶ月あたりの正確な食費を自動算出するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/pet-food-calorie-cost-manager/）。
2. 画面の指示に従って操作します。
